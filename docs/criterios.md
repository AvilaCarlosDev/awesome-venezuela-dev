# Criterios de inclusión y candidatos descartados / Inclusion criteria and rejected candidates

[Español](#español) · [English](#english)

## Español

Un recurso entra en la lista solo si cumple **todo** esto, comprobado en la fuente y no de oídas:

1. **Funciona hoy:** el enlace responde y, si es un servicio, devuelve datos actuales.
2. **Está activo:** cambios o publicaciones en los últimos 12 meses.
3. **Es verificable:** se puede ver quién lo mantiene, su licencia o su código.
4. **Es relevante para desarrolladores en Venezuela** y no duplica lo que ya hay.
5. **No es publicidad** ni una entrada a un servicio comercial disfrazada de recurso.

## English

A resource enters the list only if it meets **all** of this, checked at the source and not by hearsay:

1. **It works today:** the link responds and, if it is a service, it returns current data.
2. **It is active:** changes or posts in the last 12 months.
3. **It is verifiable:** you can see who maintains it, its license or its code.
4. **It is relevant to developers in Venezuela** and does not duplicate what is already there.
5. **It is not advertising** or a commercial service funnel disguised as a resource.

### Candidates evaluated on 2026-09-19 and rejected

| Candidate | Reason |
|---|---|
| `rafnixg/bcv-api` (★29) | Its own README says the API is outdated and its endpoints are down. |
| `dolar-vzla.rafnixg.dev` | It responds and returns today's rates, but it is a personal service with no public code or guarantees; DolarAPI is preferred, being MIT-licensed with commercial users. |
| Python Venezuela (`pyve`) | No changes since April 2024 and its official site `python.info.ve` does not respond. |
| Caracas Software Development Meetup | 469 members, but no upcoming events and no verifiable dates for past events. |
| Venezuela Tech Week | A single known edition (May 2026) and no next edition announced. |

| `Ubuntu-ve` | No changes since 2023. |

| Payment guides (Payoneer, Wise, Deel…) | The ones found were commercial blogs by the same platforms. Availability from Venezuela depends on sanctions and changes; verify it at each platform's official source. |
