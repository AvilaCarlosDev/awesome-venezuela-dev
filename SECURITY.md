# Política de seguridad / Security policy

[Español](#español) · [English](#english)

## Español

Este repositorio es una lista de enlaces y no ejecuta código de terceros ni aloja un servicio. Lo que sí puede ser un problema de seguridad:

- un **enlace malicioso** (phishing, malware, estafa) o un recurso que cambió de dueño y ahora es peligroso;
- **datos personales** de alguien publicados sin su permiso;
- credenciales o secretos incluidos por error en un commit.

### Cómo reportar

Usa el aviso privado de vulnerabilidades de GitHub: <https://github.com/AvilaCarlosDev/awesome-venezuela-dev/security/advisories/new>. Para un enlace roto o un recurso obsoleto (sin riesgo), abre un issue normal.

No incluyas en el reporte credenciales ni datos personales. Solo se mantiene la rama `main`.

## English

This repository is a list of links; it does not run third-party code or host a service. What can be a security problem:

- a **malicious link** (phishing, malware, scam) or a resource that changed owner and is now dangerous;
- **personal data** of someone published without their permission;
- credentials or secrets committed by mistake.

### Reporting

Use GitHub's private vulnerability reporting: <https://github.com/AvilaCarlosDev/awesome-venezuela-dev/security/advisories/new>. For a broken link or an outdated resource (no risk), open a regular issue.

Do not include credentials or personal data in the report. Only the `main` branch is maintained.
