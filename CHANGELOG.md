# Changelog

All notable changes to this project are documented in this file. / Todos los cambios relevantes del proyecto se documentan en este archivo.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This is a curated list, not versioned software, so entries are grouped by date. / Es una lista curada y no software con versiones, así que las entradas se agrupan por fecha.

## 2026-09-19

### Added / Añadido

- Inclusion criteria, two verified resources and a record of rejected candidates with the reason. / Criterios de inclusión, dos recursos verificados y registro de candidatos descartados con su motivo.
- Test that checks both READMEs (Spanish and English) link to the same resources. / Prueba que comprueba que los dos README (español e inglés) enlazan los mismos recursos.
- Bilingual README, real policies and the canonical CC0 license text. / README bilingüe, políticas reales y el texto canónico de la licencia CC0.

### Changed / Cambiado

- CI: actions pinned by hash, parity check, secret scanning (gitleaks) and AI-watermark check; the quality workflow can be run on demand. / CI: acciones fijadas por hash, verificación de paridad, escaneo de secretos (gitleaks) y de marcas de agua de IA; el flujo de calidad se puede lanzar a demanda.

## 2026-09-14

### Added / Añadido

- Weekly Markdown link check so the list cannot rot silently. / Revisión semanal de enlaces Markdown para que la lista no se pudra en silencio.

### Fixed / Corregido

- Removed dead links and pointed the communities section to the maintained OpenVE directory. / Se eliminaron enlaces muertos y la sección de comunidades apunta al directorio mantenido OpenVE.
- Link-check workflow: authenticated with `GITHUB_TOKEN`, cached results, updated for removed flags. / Flujo de enlaces: autenticado con `GITHUB_TOKEN`, con caché y ajustado a las opciones eliminadas.
