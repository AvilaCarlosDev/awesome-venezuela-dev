## Communities

The Venezuelan tech community lives mainly on Telegram, and a community directory already exists that is better than any partial list that could be duplicated here:

**👉 [OpenVE / comunidades-en-telegram](https://github.com/OpenVE/comunidades-en-telegram)** — more than 100 groups and channels (Python, JavaScript, PHP, Linux, Rust, WordPress, SysAdmin, QA, Women in Tech, job boards…), each with its administrators.

> **Note:** that directory's last change is from April 2024 and it has open issues nobody has answered, so some groups may have changed their link or closed.

## Remote work from Venezuela

This is where a Venezuelan developer needs specific information that generic lists do not give.

Points worth settling before applying for anything remote:

1. **How you will get paid.** Many platforms do not operate with Venezuela. Check the payment method **before** investing time in the process.
2. **Your written English.** For most remote openings it weighs more than spoken English.
3. **Time zone.** Venezuela (UTC-4) overlaps well with the US East Coast; use it as an argument in your favor.
4. **Power and internet backup.** Mention it proactively: in a remote interview it is a real objection and anticipating it helps you.

## State of the list

This list is small on purpose and maintained by one person:

- **Checked automatically:** that links respond, every week and on every change to a `.md` file.
- **Not checked:** that resources remain useful or good; that depends on the maintainer's review. Telegram groups cannot be checked automatically.
- Only one developer is in the table, the maintainer: the list grows if people contribute.

## How to contribute

1. Fork the repository
2. Create a branch: `git checkout -b add-resource`
3. Commit: `git commit -m "feat: add X"`
4. Open a Pull Request

**One firm rule:** the link must work and the resource must be active. A directory with dead links is useless to everyone — that is why a workflow checks them every week.

See [CONTRIBUTING.md](CONTRIBUTING.md) for more detail.
